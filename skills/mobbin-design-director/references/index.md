# Topic index

Load the smallest set that answers the task. The source dossiers explain why;
the operational modules below explain what to do. Do not read all dossiers on
every invocation.

| Question or trigger | Read |
|---|---|
| Avoid missing lessons, select task checks, track departures and evidence | [Coverage workflow](coverage.md), `principles-index.md` (one line per principle), `principles.json` via `coverage.py search` |
| Any claim about evidence, limits, or what was verified | [Evidence rules](evidence.md) |
| Does this look like a tool default? | [Defaults detector](defaults-detector.md) |
| The brief resembles a common job, or how do the rules combine? | [Worked examples](worked-examples.md) |
| What exactly did an Apple session or a craft essay say? | [WWDC digests](wwdc-digests.md), [Craft digests](craft-digests.md) |

| Confusing, dense, hard to learn or remember | [Cognition](cognition.md) |
| Find, critique, and improve references; Mobbin unavailable | [Research](research.md) |
| Translate book principles into observable research questions | [Research lenses](research-lenses.md) |
