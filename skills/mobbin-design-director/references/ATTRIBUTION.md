## Ideas (no text copied)

These sources shaped the skill. Their ideas were rewritten in our own words, so
no licence notice is required. The credit is a courtesy.

- mobbin/skills (MIT, Mobbin): don't write the answer you're researching
  into a query; board rules for contact sheets.
- ddruids/mobbin-skill (MIT, Murphy Usifo): turning a problem into a
  description of the visible screen, with state; putting study effort into
  the risky moments.
- richhemsley3/claude-design-skills (MIT, Rich Hemsley): behavioural evals
  that check routing decisions.
- dawitlabs/ui-skills (MIT): measuring rendered styles instead of judging
  them by eye.
- humbleteam/design-review (MIT, Humbleteam): an objective finding must
  connect a criterion to observable evidence. The earlier skill also adopted a
  six-finding cap and fixed closing format; v2 keeps evidence grounding and lets
  scope and consequence determine the useful report length.
- OpenAI Codex skills and plugins: a single combined comparison image at
  one scale; review outcomes (adapted in v2 to state actual verification coverage);
  `agents/openai.yaml` metadata;
  keep SKILL.md short and references one level deep. Ideas only: OpenAI's
  product-design plugin is proprietary, and no text from it is used.


## v2 book-informed method

The source dossiers contain original paraphrases and applications derived from
user-provided copies of The UX Book (2nd ed.), About Face (4th ed.), Designing
Interfaces (3rd ed.), Designing with the Mind in Mind (2nd ed.), and Chauncey
Wilson's User Interface Inspection Methods. v2.1 adds Steven Hoober's Touch Design
for Mobile Interfaces (2021). v2.2 adds Yvonne Rogers, Helen Sharp and Jennifer
Preece's Interaction Design: Beyond Human–Computer Interaction (6th ed., 2023)
and Adham Dannaway's Practical UI (2nd ed., 2024). Bibliographic identity, file hashes,
page locators, reading coverage, exclusions, and visual checks are maintained in
[the source index](sources/README.md). The books and their illustrations retain
their respective copyrights; no PDF, raw extraction, or book image is distributed
with this skill. Their inclusion as intellectual sources does not imply author
or publisher endorsement. Existing MIT attribution above is preserved.
